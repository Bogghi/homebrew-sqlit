# homebrew-sqlit

Homebrew tap for [sqlit](https://github.com/Maxteabag/sqlit), a user-friendly TUI for SQL databases.

## Install

```sh
brew install bogghi/sqlit/sqlit
```

or

```sh
brew tap bogghi/sqlit
brew install sqlit
```

Then run `sqlit`.

## Upgrade / uninstall

```sh
brew upgrade sqlit
brew uninstall sqlit
```

## Updating the formula

Bump `url` and `sha256` in `Formula/sqlit.rb` to the new `sqlit-tui` sdist on PyPI.
